# Contributing to the Satchel site

Thank you for wanting to help. This is the Jekyll site at
[satchel.viboko.dev](https://satchel.viboko.dev), which explains the project.
Corrections, clearer wording and fixed links are all welcome.

## Making a change

1. **Open an issue first** for anything bigger than a small fix, such as a
   new page, so we can agree on it before you spend time on it.
2. **Fork the repository** and branch off an up-to-date `main`.
3. **Make your change.** [README.md](README.md#running-locally) says how to
   run the site locally.
4. **Run the checks** in [README.md](README.md#checks), and check they pass.
5. **Write commit messages as plain sentences**, such as "Add GoatCounter
   tracking", not Conventional Commits.
6. **Open a pull request** against `main`, saying why the change is needed
   as well as what it does.

## The Contributor Licence Agreement

Before your first pull request here can be merged, a bot asks you to sign
the [Contributor Licence Agreement](https://satchel.viboko.dev/cla/v1/), by
posting a comment. You only do this once in this repository.

You keep the copyright in what you contribute. The agreement gives the
maintainer permission to publish it under whichever licence the project
chooses.
